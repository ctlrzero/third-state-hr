An off-cycle payroll is a separate run for a one-off payment or a final settlement. It is not part of the monthly run.

## Steps
1. Open **Payroll**.
2. Tap **Off-cycle / final settlement**.
   ![Off-cycle button](shot:payroll-offcycle-button)
3. Type a **Label**, for example "Final settlement – name".
4. Set the **Pay date**.
5. Add a **Salary month (optional)** if the payslip should show a month.
6. Tap **Create**.
   ![Off-cycle form](shot:payroll-offcycle-form)
7. Under **Add an employee to this off-cycle payroll**, choose the person and tap **Add**.
8. Open their record. Fill **Leaving (final settlement)** with the **Last working day** and the settlement items.
9. Approve, record payment and publish as normal.

## What happens next
The run appears in the month list with its label. People are prepared in it like in a monthly run. Items such as **End-of-service gratuity**, **Leave encashment** and **Notice pay** are available as one-off earnings.

For normal monthly salary, use **Prepare payroll** for that month instead.

## Common problems
- **Create is greyed.** Type a **Label** first.
- **The person is not in the list.** Only people not already in this run can be added.
- **I need to start offboarding first.** See the offboarding guide.
